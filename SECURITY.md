# Security Policy

## Supported versions

Security fixes are applied to the latest version of this action on the default
branch. Consumers should pin a released commit or immutable action reference
and update it when security fixes are published.

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue, pull request,
or discussion. Use a private GitHub Security Advisory for this repository, or
contact the repository maintainers directly if private advisory reporting is
unavailable.

Include the affected reference, reproduction steps, security impact, and any
suggested mitigation. Remove credentials, signing keys, personal data, and
other sensitive values from the report.

We will acknowledge valid reports, coordinate a fix with the reporter, and
publish remediation details after a fix is available.
